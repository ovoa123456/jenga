# 우리 사이 젠가 — 온라인 멀티플레이

## 로컬 실행
1. Node.js 18 이상 설치
2. 프로젝트 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 접속

## 무료 배포 예시 (Render)
1. 이 프로젝트를 GitHub 저장소에 업로드
2. Render에서 **New → Web Service** 선택 후 저장소 연결
3. Runtime: Node, Build Command: `npm install`, Start Command: `npm start`
4. 배포가 끝나면 Render가 제공하는 `https://...onrender.com` 주소로 접속
5. 한 명은 방 만들기, 다른 한 명은 초대 링크로 접속

무료 호스팅의 수면/사용량 제한은 제공업체 정책에 따라 달라질 수 있습니다.

## 현재 프로토타입의 범위와 주의
- 회원가입 없이 6자리 방 코드로 2명 접속
- Socket.IO로 방 인원, 질문, 턴, 블록 좌표를 실시간 중계
- 3D 물리엔진은 각 브라우저에서 실행되고 드래그한 블록의 위치/회전이 상대에게 전달됩니다.
- 이 버전은 실제 서비스 수준의 서버 권위형 물리 시뮬레이션이나 재접속 복구, 악성 입력 방어를 구현한 것은 아닙니다.
- 무료 서버가 잠들면 첫 접속에 시간이 걸릴 수 있습니다.
